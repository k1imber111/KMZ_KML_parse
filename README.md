# KML/KMZ Placemark Organizer

Утилита для группировки меток (`Placemark`) в файлах **KML** и **KMZ** по папкам.
Основной сценарий: вы выбираете файл, задаёте имя новой папки и перечень меток,
после чего создаётся **новый KMZ-файл**, содержащий только выбранные папки и метки.
Исходный файл **не изменяется**.

## Возможности

- Работа как с `.kml`, так и с `.kmz` файлами.
- Интерактивное меню: выбор между запуском и просмотром инструкции.
- Выбор файла через путь или передачей аргумента командной строки.
- Два режима ввода шаблонов меток:
  - интерактивный — по одной метке за раз;
  - пакетный — **через запятую и/или двоеточие** (например: `32:33:34, 40, 41:42`).
- Поддержка поиска по точному совпадению имени метки, а при необходимости — по регулярному выражению.
- Автоматическое логирование в `kml_manager.log` и вывод в консоль.

## Установка и запуск

Требуется Python 3.8+.

```bash
cd e:\Python\Project\PythonBot_new\KMZ_KML_parse
python KMZ_new.py
```

Также можно сразу указать путь к файлу:

```bash
python KMZ_new.py "C:\Путь\к\файлу.kmz"
```

На Linux путь будет стандартным Unix-видом:

```bash
python KMZ_new.py "/home/user/maps/marks.kml"
```

## Структура проекта

- `KMZ_new.py` — тонкая оболочка-скрипт для запуска CLI.
- `kml_organizer/`
  - `core.py` — низкоуровневая работа с KML/KMZ: парсинг, поиск, создание папок, перемещение меток, сохранение и построение экспортного документа.
  - `services.py` — сервисный слой (загрузка документа, высокоуровневые операции, экспорт в отдельный KMZ).
  - `io_utils.py` — безопасный ввод/вывод и диалог с пользователем.
  - `cli.py` — логика интерактивного меню и основной сценарий работы.
  - `logging_config.py` — конфигурация логирования.

## Формат пакетного ввода меток

В пакетном режиме вы можете вводить шаблоны меток в одной строке:

- через запятую: `10,11,12`
- через двоеточие: `10:11:12`
- комбинированно: `10:11,12:13,14`

Разделители `,` и `:` считаются равнозначными и используются только как разделители
между отдельными именами меток. Пробелы по краям игнорируются.

## Результирующий KMZ-файл

- Исходный KML/KMZ не модифицируется, все изменения выполняются только в памяти.
- По завершении работы создаётся новый файл рядом с исходным, с именем вида:
  - `input.kmz` → `input_groups.kmz`
  - `input.kml` → `input_groups.kmz`
- Внутри архива содержится файл `doc.kml` со структурой, совместимой с Google Earth:
  - `<kml xmlns=\"http://www.opengis.net/kml/2.2\">` → `<Document>` → `<Folder>` → `<Placemark>`.

## Логирование

- Логи пишутся в файл `kml_manager.log` в текущей директории и одновременно выводятся в консоль.
- В логах фиксируются:
  - успешная загрузка и разбор файлов;
  - количество найденных и экспортированных меток;
  - ошибки парсинга XML, проблемы с файлами KMZ/KML и другие исключения.

## Обработка ошибок

- Все операции чтения/записи и парсинга завернуты в обработчики исключений.
- В случае ошибок вы получаете понятное сообщение и запись в логах, а не \"падение\" программы.
- Команды `!cancel` и `!exit` поддерживаются практически во всех точках ввода:
  - `!cancel` — возврат к предыдущему шагу или в меню;
  - `!exit` — немедленное завершение программы.
